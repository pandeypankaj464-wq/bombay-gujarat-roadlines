# BOMBAY GUJARAT ROADLINES
Transport & Logistics Management — Android starter app.

## Build APK on GitHub
1. Upload the complete contents of this project to the root of your GitHub repository (keep the `.github/workflows/build.yml` path).
2. Open the repository's **Actions** tab.
3. Select **Build Android APK** → **Run workflow**.
4. When the run succeeds, open it and download the artifact named `BGR-Transport-Management-debug-apk`.

The APK is a debug build for testing. Booking data is stored locally on the device and is not automatically shared between phones. This starter currently supports creating and viewing basic bookings; payments, contacts, reports, cloud sync and other advanced modules are not yet implemented.
